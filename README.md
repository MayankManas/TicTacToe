# ❌⭕ Tic-Tac-Toe (Android)

A simple **Tic-Tac-Toe** game built for **Android** using Java/Kotlin.  
Play against your friends locally on the same device in the timeless 3x3 grid challenge 🎮.

---

## 📱 Features
- Classic 3x3 Tic-Tac-Toe board.
- Two-player mode (play locally).
- Highlights winning combinations.
- Tracks game status (X wins, O wins, or Draw).
- Clean and minimal UI for smooth gameplay.

---

## 🕹️ How to Play
1. Player **X** always starts first.
2. Players take turns marking empty cells.
3. The first to align **three marks** (horizontally, vertically, or diagonally) wins.
4. If the board fills without a winner → **Draw**.
